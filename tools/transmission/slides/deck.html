The problem

Codebases drift. Silently.

The gap between what your repo says it does and what it actually does widens every week — and nobody notices until it costs real hours.

📖 Docs lie

References to files that moved, env vars that were renamed, "last audited" dates that are months stale.

🔓 Auth is load-bearing, untested

One wrapper guards every mutation, but there's no regression test proving anonymous callers get rejected.

🪦 Dead code misleads

Deprecated fields and unused exports stay in the schema, confusing the next developer who reads it.

⚠️ It compounds

None of it fails loudly. It surfaces later as incidents, failed audits, and 3-week onboardings.

Existing tools are one-shot linters: static report, lost context, read once.

Actionable in 10 minutes

Application of IBM Bob 2.0

Bob is the orchestrator — five subagents, one pass.

The audit is a reusable Bob skill using Agent mode, parallel subagents, and document understanding. Bob reads the team's stated beliefs (AGENTS.md, docs/remote-apis.md) and checks them against the source.

🌐

Remote APIs

Call sites, gating, fallbacks, PII — vs the inventory doc.

⚙️

Backend health

Auth, validators, indexes, dead exports, schema drift.

📖

Doc drift

Every factual claim verified against current source.

🧪

Test gaps

High-value functions with zero coverage.

🔒

Security

.gitignore, hardcoded secrets, risky TODOs.

→ dedupe, cap at 30, sort by severity → structured JSON → rendered transmission. Stays within the 40-Bobcoin budget.
